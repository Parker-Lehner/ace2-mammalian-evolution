# Data Availability

All retained sequence records are public ACE2 records from NCBI/RefSeq-style sources, with fallback public metadata retained separately where applicable. Generated analysis outputs, scripts, figures, and manuscript sources are included in this release package.

Before journal submission:

1. Push this repository to GitHub as `ace2-mammalian-evolution`.
2. Keep the repository private during internal review if desired.
3. Create a tagged release, e.g. `v1.0.0-submission`.
4. Archive that release with Zenodo.
5. Replace manuscript placeholders with the final GitHub URL and Zenodo DOI.

Draft manuscript wording after DOI creation:

> All sequence metadata, alignments, analysis scripts, model outputs, and figure-generation code are available at [GitHub URL] and archived at [Zenodo DOI].
