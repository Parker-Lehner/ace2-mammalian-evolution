# Data Availability

All retained sequence records are public ACE2 records from NCBI/RefSeq-style sources, with fallback public metadata retained separately where applicable. Sequence metadata, processed results, figure-generation code, manuscript sources, and reproducibility materials are included in this repository.

The GitHub repository is available at https://github.com/Parker-Lehner/ace2-mammalian-evolution. A versioned Zenodo archive will be created before publication, and the DOI will be added to the accepted version.
